Steerholm is one surface with two faces. To your AI agents it's an **action
plane** — the single place they connect to and act. To you it's a **control
plane** — where you decide what every agent can reach and do, down to the
individual action and its arguments. Nothing runs that you didn't allow.

New here? [Install Steerholm](/getting-started/installation), then the
[quickstart](/getting-started/quickstart) gets you to a scoped agent in minutes.
For the full mental model, see [the control plane](/concepts/control-plane).

## Why it exists

Today each agent configures its own MCP servers, with no shared management and no
way to limit what an agent can do once it's connected. Steerholm brings them onto one
plane you control: agents act in one place, and every action is checked against
your policy before it reaches a server.

## Agents, servers, and grants

<CardGroup cols={3}>
  <Card title="Agents" icon="robot" color="#10b981">
    The AI tools you govern — Claude Code, Cursor, VS Code, OpenCode. Each has a
    name, an access key, and a policy.
  </Card>

  <Card title="Servers" icon="server" color="#10b981">
    The MCP servers you add. Each one exposes tools — the capabilities an agent
    might use.
  </Card>

  <Card title="Grants" icon="key" color="#10b981">
    Scoped access from an agent to a server's tools — per tool, per argument.
    No grant means no access.
  </Card>
</CardGroup>

Two things you **add** — agents and servers — and one governed connection you
**grant** between them. See [Permissions](/concepts/permissions) for the tool and
argument syntax.

## Set it up in three moves

<Steps>
  <Step title="Add a server">
    Register an MCP server once; the daemon starts and supervises it.

    ```bash
    holm add server git --command "uvx mcp-server-git"
    ```
  </Step>

  <Step title="Add an agent">
    Register an agent and get its access key — the credential it connects with.

    ```bash
    holm add agent coding-agent
    ```
  </Step>

  <Step title="Grant scoped access">
    Give the agent exactly the tools it needs, down to the argument.

    ```bash
    holm grant coding-agent database --tool "query" --args "sql=re:^SELECT"
    ```
  </Step>
</Steps>

Then point the agent at `http://127.0.0.1:4767/mcp` with its access key — see
[Add an agent](/guides/add-an-agent). It sees only the tools its policy
allows.
